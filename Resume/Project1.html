Description of the project

Converted a research paper into an informational website by organizing content into easy-to-follow pages and sections, adding internal navigation and a glossary for key terms, and including a Works Cited page to support the information with sources.

Skills learned from completing the project

  • Semantic HTML and multi-page website structure
  • CSS styling (layout, spacing, typography, consistent design)
  • Clear navigation design (menus, internal links, anchor links/breadcrumbs)
  • Adding and citing sources (Works Cited, external links, image credits)
