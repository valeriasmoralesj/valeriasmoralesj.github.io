Description of the project

Built a simple workout planning app that lets users create workout plans and manage exercises within each plan (sets, reps, optional weight/notes). Used a Room database with a one-to-many relationship to save data on-device and support full CRUD actions, based on requirements gathered from a user interview.

Skills learned from completing the project

  • Android app development in Java
  • Room database and on-device data persistence
  • Data modeling with a one-to-many relationship
  • Implementing full CRUD functionality
